# 🚀 Computer Architecture & Organization (CAO) — Interactive Masterclass

> Complete, student-friendly interactive course suite & exam revision hub for Computer Architecture & Organization (CAO) based on John P. Hayes' syllabus for Daffodil International University (DIU CSE).

🔗 **Live Website:** [https://hossain-joy.github.io/computer-architecture-masterclass/](https://hossain-joy.github.io/computer-architecture-masterclass/)

---

## 🌟 Key Features

- **🌐 100% Bilingual Support:** Instant toggle between English (`en`) and Bengali (`bn`) with full text and simulator synchronization.
- **📱 Fluid Mobile Responsiveness:** Fully optimized for smartphones, tablets, and desktops with touch-friendly controls.
- **🎮 Gamified Learning (Architect Academy):**
  - Live XP tracking, Streak counter, and 11 Unlockable Academic Badges.
  - Floating Gamer HUD & Academic Passport Modal.
  - Interactive retro synthesizer audio feedback.
- **⚡ Interactive Hardware Simulators:**
  - **Soroban Abacus & Slide Rule** (Lecture 1)
  - **Babbage Analytical Engine & IAS 40-Bit Word Visualizer** (Lecture 2)
  - **Ripple Carry Adder & Logic Gate Playground** (Lecture 3)
  - **Radix Base Converter, 2's Complement & Binary Ninja Speed Run** (Lecture 4)
  - **Endianness Memory Layout & 2-Stage Instruction Pipelining** (Lecture 5)
- **🎯 Exam Master Vault:**
  - Bloom's Taxonomy Level 3 (Apply) mathematical problems with step-by-step model solutions.
  - Architecture blueprints, memory layout diagrams, and circuit schematics.
- **🧪 Interactive Self-Assessment Quizzes:** 5-question multi-choice exam with immediate feedback, detailed explanations, and score tracking.
